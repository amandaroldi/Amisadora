# Amisadora

Olá, seja bem-vindo ao **Amisadora**! É um prazer apresentar nosso projeto, desenvolvido como atividade das disciplinas de **Programação Web** e **Banco de Dados**. Aqui, você poderá conhecer um pouco sobre o funcionamento do nosso site e as tecnologias utilizadas.

O Amisadora é um site de uma loja virtual de moda, desenvolvido como projeto das disciplinas de Programação Web e Banco de Dados. O site foi feito utilizando **HTML, CSS e PHP**, com o **XAMPP** para executar o projeto localmente.

No site, é possível visualizar os produtos, realizar cadastro e login, adicionar produtos ao carrinho e escolher uma forma de pagamento. O sistema também utiliza sessões para manter algumas informações durante a navegação.

Para a parte de Banco de Dados, foi utilizado o **MySQL**, com o banco chamado `amisadora`. Ele é responsável por armazenar e organizar informações como usuários, produtos e vendas. O PHP faz a conexão com o banco e utiliza comandos SQL para consultar e inserir os dados, fazendo com que as informações não fiquem armazenadas apenas nos arquivos do site.

Para executar o projeto, é necessário colocar a pasta na `htdocs` do XAMPP, iniciar o Apache e o MySQL, criar o banco `amisadora` no phpMyAdmin e importar o arquivo SQL com as tabelas do sistema.

Esperamos que goste de conhecer o nosso projeto e tenha uma boa experiência navegando pelo Amisadora!
